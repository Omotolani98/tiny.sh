# Tiny.sh
![Go](https://img.shields.io/badge/-Golang-00ADD8?style=flat&logo=go&logoColor=white)

Simple Idea to manage a server over a TUI, these includes ssh key managements, monitor server health with CPU, Memory & Storage metrics, File Managements. I built it for myself to
make it easier to manaage servers. It becomes a bit cumbersome repeating commands, jumping between multiple terminal tabs or tmux sessions. I built this to boost my productivity.
